acoustotreams.plane_wave_angle_scalar¶

acoustotreams.plane_wave_angle_scalar(theta, phi, **kwargs)[source]¶

Array describing a scalar plane wave given by its propagation angles.

The propagation direction is the unit vector \((\sin\theta \cos\varphi, \sin\theta \sin\varphi, \cos\theta)\). The wave is created with plane_wave_scalar().

Parameters:

  • theta (float) – Polar angle of the propagation direction, measured from the z axis (rad).

  • phi (float) – Azimuthal angle of the propagation direction, measured from the x axis in the xy plane (rad).

  • **kwargs – Keyword arguments passed to plane_wave_scalar(): k0, basis, material, and modetype. If no basis is given, a ScalarPlaneWaveBasisByUnitVector containing only this propagation direction is used.

Returns:

AcousticsArray
